# Prelimina 0.3.2

More reliable simulations and faster workflows

## Changes

- Explore how a setup differs from the defaults with a step-by-step settings tour.
- Sharp-interface FLIP can use well-balanced gravity without liquid drifting from rest, including in compressible-gas cases.
- Run compressible-gas simulations during rotating-frame motion, with gas pressure staying consistent as gravity, rotation, acceleration, or the pivot changes.
- Run compressible gas with sharp interfaces and density projection in FLIP simulations.
- Sealed-ullage simulations can exchange mass with the liquid through evaporation and condensation, and results include ullage state and liquid-side interface heat.
- Tank meshes can seal a pressure domain without declaring every box face a wall, and sealed ullages retain pressure support.
- Closed tanks with baffles keep liquid from escaping through narrow wall gaps, while passive-gas simulations no longer classify wall support cells as gas.
- Sharp-interface FLIP stays stable around nearly closed cut faces instead of developing extreme velocities.
- Prescribed heat flux on curved walls is applied more consistently.
- Thermal simulations avoid spurious failures on already-converged solves, and failed solves provide clearer diagnostics.
- FLIP PBD simulations run faster.
- FIRM pressure solves and initialization run faster.

## Requirements and limitations

These binaries are unsigned. A Vulkan-capable GPU and vendor driver are required. CUDA and macOS packages are not included. Back up projects and keep them outside the installation directory.
