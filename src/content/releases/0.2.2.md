# Prelimina 0.2.2

## Changes

- Scene simulation previews now start automatically after loading, use the Balanced setting, and show cached time ranges in the scrubber.
- Scene drafts now account for simulation cost when choosing their size, condition particles before projection, and can resume after releasing a running simulation.
- FLIP now uses least-squares interface curvature by default and can automatically enable density projection on supported desktop backends.
- FLIP density projection now handles recoverable rejected candidates without aborting the simulation.
- FLIP wall handling and contact-line damping have been corrected for particle movement and viscosity boundaries.
- FVM now preserves liquid volume and co-moving flow more consistently across moving-boundary recuts.
- FVM now warns when a moving body is used without cell pairing, and rejects gas-interface damping with the consistent corrector.

Breaking changes: existing projects or workflows may need changes before use.

- FLIP: `flip.density_projection.enabled` is no longer accepted. Use `flip.density_projection.mode` instead (`"on"` replaces `enabled: true`, `"off"` replaces `enabled: false`). Scenes without an explicit setting now use density projection where supported. A checkpoint saved without density projection can be resumed only with `mode: "off"` if the scene would now enable it automatically.
- FVM: setups that set `fvm.multiphase.gas_interface_alpha_u` below 1 with the default consistent corrector no longer load. Remove the field, or set `fvm.multiphase.corrector` to `"legacy"` to keep the previous damping.

## Requirements and limitations

These binaries are unsigned. A Vulkan-capable GPU and vendor driver are required. CUDA and macOS packages are not included. Back up projects and keep them outside the installation directory.
