# Prelimina 0.2.5

More reliable flows and CFD tooling

## Changes

- Violent FLIP sloshing is less likely to be overdamped when particles travel multiple cells in a step.
- Coupled moving-wall simulations avoid pressure spikes from extremely short leftover substeps.
- Setup validation warns when positive phase viscosity will not be applied in FLIP or FIRM.
- FVM setup validation catches attempts to ramp gravity during both warmup and the simulation, preventing an unintended second ramp.
- FIRM preserves slow particle motion instead of freezing or biasing displacements toward zero.
- FLIP and FIRM mesh-inlet births now start on the receiving side of the cap, preventing trapped particles and spurious air at submerged FLIP inlets.
- Planar mesh inlets keep still water at rest, and FLIP divergence checks and projection solves behave better around split inlet cells.
- FVM PLIC now handles multiple separated static bodies and rigidly moving closed meshes, with automatic exact-cut selection when setup checks allow it.
- Windows and Linux desktop releases include an Agent Pack and CLI/MCP tools for setup validation and task-based CFD runs.
- Linux users can run a packaged FLIP dam-break against an elastic obstacle with the included CalculiX and preCICE tools.
- Two-phase PF-FLIP simulations can use volume correction to limit liquid-volume drift during expansion.
- PF-FLIP can derive its reference density from particle packing, adapting when particle count or kernel radius changes.

## Requirements and limitations

These binaries are unsigned. A Vulkan-capable GPU and vendor driver are required. CUDA and macOS packages are not included. Back up projects and keep them outside the installation directory.
