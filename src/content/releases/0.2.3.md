# Prelimina 0.2.3

## Changes

- Single-liquid FLIP now enables the carried-phi level set by default in supported setups and can initialize it from expression and triangle-mesh interfaces.
- Passive-void free surfaces in FVM now move at the liquid's speed.
- FLIP contact-angle wetting now works on cut and curved mesh walls and avoids wall-induced bias in two-phase flows when an angle is set.
- FVM exact-geometry mode now supports static closed triangle meshes as obstacles or inverted containers.
- FVM now automatically selects split PLIC alpha transport when the simulation setup supports it, while retaining MHRIC for other setups.
- FVM initialization now handles cut-volume samples that fall on oblique walls or interfaces.
- FLIP more reliably preserves solid tank walls when multiple colliders are nearby.
- Carried-phi FLIP now handles initial interfaces along walls more consistently, improving still-fluid behavior in tanks.
- FLIP pressure and density-projection solves wait on the GPU less often per step, with unchanged results.

Breaking changes: existing projects or workflows may need changes before use.

- `flip.interface.level_set.carried_phi_level_set` is replaced by `flip.interface.level_set.carried_phi_mode` (`auto`, `on` or `off`); setups that use the old key are rejected with a pointer to the new one. `auto`, the default, now uses the carried-phi level set for single-liquid FLIP. Set `off` to keep the previous particle-splat level set, including when restoring checkpoints written with it.

## Requirements and limitations

These binaries are unsigned. A Vulkan-capable GPU and vendor driver are required. CUDA and macOS packages are not included. Back up projects and keep them outside the installation directory.
