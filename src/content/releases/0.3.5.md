# Prelimina 0.3.5

More reliable fluid simulations and ullage controls

## Changes

- Prescribed-body load results now include capillary pull and the liquid pressure head up to the wall.
- Regularized-rheology and Bingham FLIP runs no longer stop before a required solve or fail when the residual reaches zero.
- FLIP velocity sampling near closed walls now respects the wall rule for particle transfers, tracers, and free-surface motion.
- Density projection now classifies pressure cells consistently and avoids acting on underdensity estimates when particle support is incomplete.
- FVM Stokes simulations can initialize when cell centres lie inside an exact solid.
- Setup validation now points to the user-facing setting when rejecting unsupported backflow, pressure-nullspace, momentum-transport, or carried-phi combinations.
- Seeded single-phase FVM setups can now use alpha FCT.
- Particle capture now works correctly across phase and option combinations.
- Hydrostatic-split FLIP pressure solves converge reliably when no tolerance is specified.
- Viscous FLIP runs retain sampled face contributions where walls clip the fluid.
- Still FIRM tanks with adaptive time stepping no longer let the wall layer fall under gravity.
- Still tanks using PBD wall curvature and density projection no longer develop spurious currents at startup.
- Surface-tension-driven flows can use semi-implicit surface tension in single-liquid, passive-gas, and PF-FLIP runs with less damping and fewer capillary-step restrictions; particle-splat interfaces remain the default, and carried phi is retained above the capillary limit.
- PF-FLIP viscosity no longer extends through the particle-free void.
- Sealed-inlet fills no longer create incorrectly phased particles near the walls.
- Density-projected particles no longer distort the particle level set when they move across the interface, and carried-phi interfaces stay centered on the particle distribution and still when particle motion is frozen.
- FIRM surface-pressure forces are integrated more reliably around adjacent curved box faces.
- FVM cut walls now close grid-aligned apertures and volumes correctly, and prescribed body motion updates the cut geometry each step.
- Later PISO pressure corrections now use a consistent convergence reference, helping avoid premature stopping.
- Reactive FVM bodies remain better balanced in still water, and their setups now initialize with the appropriate pressure treatment.
- Seeded FLIP fills can now use monolithic six-degree-of-freedom bodies when each step has a connected liquid component.
- The command line can write selected outputs when an accepted state first exceeds a chosen represented-speed threshold.
- Free-surface recording no longer ends the run when surface velocity cannot be sampled for a frame; the frame is skipped with a reason, or unsampled velocity components are written as missing data.
- Implicit interface gravity is now available for single-liquid free surfaces and sharp PF-FLIP interfaces when hydrostatic split is enabled.
- PF-FLIP now treats unspecified domain faces as walls, so projects that rely on gas passing through those faces must explicitly specify the intended boundary behavior.
- Single-liquid FLIP now supports lumped-vapor ullage, with relief venting for particle or lumped vapor and heat exchange with thermal and convective walls for lumped vapor.
- Lumped-vapor ullage can now use regulated pressurant and prescribed-flow liquid inlets and outlets.
- Ullage vent and pressurant set pressures can now follow time-based keyframe schedules.
- Restart checkpoints and retried steps now preserve the lumped-vapor ullage state.
- Hybrid FLIP/APIC transfers now retain affine particle motion when velocity samples are unpaired.

Breaking changes: existing projects or workflows may need changes before use.

## Requirements and limitations

These binaries are unsigned. A Vulkan-capable GPU and vendor driver are required. CUDA and macOS packages are not included. Back up projects and keep them outside the installation directory.
