# Prelimina 0.2.4

## Changes

- FVM free-surface transport now handles moving and cut cells more consistently, including pressure and wall loads.
- Pressure outlets now support a hydrostatic reference level, helping preserve still water under gravity.
- Hybrid FLIP/APIC transfers now retain affine motion across steps, including near domain walls and immersed colliders.
- FLIP free-surface recording now handles surface velocities near curved walls more reliably.
- FLIP simulations can initialize faster by compiling only the transfer samplers used by the run.
- Harmonic axis and direction fields now retain entered values when applied and reloaded, with blank components treated as zero.
- Simulation initialization now explains that the device is being optimized and that later runs start faster.
- Preview priority now affects the balance between rendering and solving during idle playback.
- FVM now flags unsupported wall-pressure boundary conditions when using exact geometry.

## Requirements and limitations

These binaries are unsigned. A Vulkan-capable GPU and vendor driver are required. CUDA and macOS packages are not included. Back up projects and keep them outside the installation directory.
