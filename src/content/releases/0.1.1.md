# Prelimina 0.1.1

## Changes

- FLIP now supports planar mesh inlets with density projection, including split-cell flow and free-surface boundaries.
- FLIP supports planar disposal outlets with IDP.
- The liquid level set now continues into walls by default, improving still-water behavior in closed curved containers while keeping extracted surfaces clamped to the collider.
- Prescribed body rotations now use the configured reference rotation center.
- Density projection and PBD now handle particle corrections near curved walls without rejecting otherwise admissible positions.

## Requirements and limitations

These binaries are unsigned. A Vulkan-capable GPU and vendor driver are required. CUDA and macOS packages are not included. Back up projects and keep them outside the installation directory.
